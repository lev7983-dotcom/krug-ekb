КРИТИЧЕСКИ ВАЖНО
Текущие Render и Neon не подтверждают первичное хранение персональных данных
граждан РФ на территории России. Не собирайте там реальные телефоны, Telegram-
профили и фотографии. Перед настоящим запуском перенесите сервер, базу, резервные
копии и фотографии в российский дата-центр.

Ранее опубликованный Telegram-токен нужно немедленно отозвать через BotFather.
Новый токен нельзя отправлять в чат, добавлять в код, GitHub или скриншоты.

ПРОВЕРКА УЖЕ ОПУБЛИКОВАННОГО БОТА
Дважды нажмите «ПРОВЕРИТЬ-РАБОЧЕГО-БОТА.bat». Скрипт ничего не меняет и не
показывает секреты: он сверяет версию API и HTML, Git-коммит, Telegram API и
webhook. Для точной проверки версии: python verify_release.py --expected v122

Релиз v118: добавлен безопасный фундамент партнёрского импорта. Администратор может
зарегистрировать конкретную Telegram-группу или сообщество VK. Сообщения принимаются
только от активных разрешённых источников и сохраняются как личные черновики владельца;
автоматической публикации и HTML-парсинга чужих страниц нет. Для Telegram бот должен
быть официально добавлен в партнёрскую группу. Подключение VK выполняется только через
официальный Callback API сообщества и будет включено после получения ключей владельца.

Релиз v119: добавлен официальный endpoint `/api/vk/callback`. Он проверяет секрет
сообщества, отвечает строкой подтверждения VK и принимает новые записи стены только
от включённых сообществ. Запись создаёт личный черновик владельца источника; секрет
хранится только в виде SHA-256 хеша.

Релиз v120: Telegram-группа подключается командой `/krug_source`. Бот проверяет
через Telegram API, что команду отправил создатель или администратор группы, и только
после этого включает источник. Повторная доставка одного события не создаёт дубликат.

Релиз v121: сообщения партнёрских групп проходят фильтр автомобильного объявления.
Обычная переписка не сохраняется: требуется цена и хотя бы один автомобильный признак
(год, пробег, марка либо слова о продаже/обмене).

Релиз v122: в профиле появился список импортированных черновиков. Их можно открыть,
проверить и удалить, поэтому черновик не потеряется после закрытия Telegram-уведомления.

ПОЧЕМУ НОВЫЕ TELEGRAM-ПРОФИЛИ ПОКА ОГРАНИЧЕНЫ
Личные функции включаются только после заполнения секретов DATABASE_URL,
LEGAL_OPERATOR_NAME, LEGAL_OPERATOR_EMAIL, LEGAL_OPERATOR_ADDRESS,
ADMIN_TELEGRAM_IDS и честного подтверждения DATA_RESIDENCY_RF_CONFIRMED=1.
Файл check_production.py проверяет наличие этих настроек, не печатая их значения.
