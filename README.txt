КРУГ — Telegram Mini App автомобильного маркетплейса Екатеринбурга

СТАТУС ВЕРСИИ V65
— каталог, поиск и ценовые фильтры;
— продажа, обмен и срочные объявления;
— избранное, просмотры, подписки и уведомления;
— подписка на выбранную марку, цену и характеристики автомобиля;
— топливо, двигатель, мощность, цвет и количество владельцев;
— сравнение до трёх автомобилей по основным характеристикам;
— Telegram-ссылки сразу открывают нужное объявление внутри КРУГ;
— личный чек-лист безопасной проверки автомобиля хранится только на устройстве покупателя;
— помощник качества объявления показывает процент заполнения и следующий полезный шаг;
— удобная форма жалобы с понятными причинами и комментарием без системных окон;
— безопасное удаление аккаунта с отдельным подтверждением внутри приложения;
— единые подтверждения для удаления объявления, отмены обмена и снятия доступа сотрудника;
— публикация показывает понятный прогресс, не зависает бесконечно и сохраняет заполненную форму при сбое сети;
— каталог показывает скелетон загрузки и кнопку повторной попытки при медленном или недоступном сервере;
— безопасная диагностика Telegram API и вебхука доступна в состоянии сервера без раскрытия токена;
— владельцу и ранее зарегистрированным знакомым доступен закрытый тестовый режим до публичного запуска;
— публичный тестовый режим открывает основные функции всем пользователям Telegram с обязательным согласием;
— исправлена загрузка главной автомобильной обложки на мобильных устройствах;
— гибкие входящие и исходящие предложения: свой автомобиль либо произвольные условия, доплата и комментарий;
— личные объявления и удаление аккаунта;
— жалобы, администраторы и модераторы;
— защита Telegram-входа и минимизация персональных данных.
— JavaScript и стили вынесены в отдельные файлы для более строгой защиты браузера.

ЛОКАЛЬНЫЙ ЗАПУСК
1. Дважды нажмите «ЗАПУСТИТЬ-КРУГ.bat».
2. Не закрывайте чёрное окно во время локальной проверки.
3. Локальный режим предназначен только для разработки и тестовых данных.

КРИТИЧЕСКИ ВАЖНО
Текущие Render и Neon не подтверждают первичное хранение персональных данных
граждан РФ на территории России. Не собирайте там реальные телефоны, Telegram-
профили и фотографии. Перед настоящим запуском перенесите сервер, базу, резервные
копии и фотографии в российский дата-центр.

Ранее опубликованный Telegram-токен нужно немедленно отозвать через BotFather.
Новый токен нельзя отправлять в чат, добавлять в код, GitHub или скриншоты.

ПОЛНАЯ ИНСТРУКЦИЯ
Смотрите SECURITY-AND-LEGAL.md. Там перечислены обязательные юридические действия,
production-переменные, уже добавленная защита, остаточные риски и тесты.

ФАЙЛ НАСТРОЕК
Скопируйте имена переменных из .env.example в секреты российского хостинга.
DATA_RESIDENCY_RF_CONFIRMED=1 можно включать только после фактической проверки.

ПРОВЕРКА
python -m py_compile server.py
python ..\work\v45_security_test.py
python check_production.py

ПОЧЕМУ НОВЫЕ TELEGRAM-ПРОФИЛИ ПОКА ОГРАНИЧЕНЫ
Личные функции включаются только после заполнения секретов DATABASE_URL,
LEGAL_OPERATOR_NAME, LEGAL_OPERATOR_EMAIL, LEGAL_OPERATOR_ADDRESS,
ADMIN_TELEGRAM_IDS и честного подтверждения DATA_RESIDENCY_RF_CONFIRMED=1.
Файл check_production.py проверяет наличие этих настроек, не печатая их значения.
